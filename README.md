字段說明（簡要）
roots：頂層空間 / 房間
nodes：中間收納分層，可掛 root / 其他 node
leafs：最底層實體物品
tempStorage：臨時存放區
parentType 只會是 root / node
可選字段：restrictedRootId、quantity 按需填寫
